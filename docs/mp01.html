#' Acquire Netflix What We Watched Reports
#' 
#' This function will acquire and standardize all data for MP#01
#' from Netflix. Because Netflix hosts the data files behind a CDN, we
#' are accessing the release pages and automatically extracting links to the
#' relevant files (with CDN hash). 
#' 
#' After import, files are stacked vertically and some basic cleaning is
#' performed. 
load_netflix_data <- function(){
  # Note to students: Make sure you have installed the tidyverse and fs packages
  #                   before beginning this assignment. If you aren't sure,
  #                   simply run `library(tidyverse)` at your R Console and, if
  #                   you don't see an error message, `tidyverse` has been 
  #                   installed. (Same for `fs`) If you still need to install
  #                   either package, use the `install.packages` function as 
  #                   demonstrated in class.
  library(tidyverse)
  library(rvest)
  library(readxl)
  library(fs)
  
  data_dir <- path("data", "mp01")
    
  if(!dir_exists(data_dir)){
    dir_create(data_dir, showWarnings=FALSE, recurse=TRUE)
  }
  
  NETFLIX_URLS <- list(
    `2023H1` = "https://about.netflix.com/news/what-we-watched-a-netflix-engagement-report",
    `2023H2` = "https://about.netflix.com/news/what-we-watched-the-second-half-of-2023",
    `2024H1` = "https://about.netflix.com/news/what-we-watched-the-first-half-of-2024",
    `2024H2` = "https://about.netflix.com/news/what-we-watched-the-second-half-of-2024",
    `2025H1` = "https://about.netflix.com/news/what-we-watched-the-first-half-of-2025",
    `2025H2` = "https://about.netflix.com/news/what-we-watched-the-second-half-of-2025",
    `2026H1` = "https://about.netflix.com/news/what-we-watched-the-first-half-of-2026"
  )
  
  download_if_needed <- function(url, local){
    if(!file_exists(local)){
      download.file(url, local, quiet = TRUE, mode = "wb")
    }
    
    return(local)
  }
    
  NETFLIX_URLS |> 
    map(read_html) |> 
    map(html_element, xpath = "//a[contains(@href, '.xlsx')]") |> 
    map_chr(html_attr, "href") |> 
    enframe("period", "url") |> 
   mutate(path = path(data_dir, paste0(period, ".xlsx")), 
          path = map2(url, path, download_if_needed), 
          data = map(path, read_excel, skip=3, na="*"), 
          data = map(data, \(x) x |> mutate(`Release Date` = as.Date(`Release Date`)))) |>
    unnest(data) |> 
    select(-url, -path) |> 
    mutate(year=str_sub(period, 1, 4), 
           half=str_sub(period, start=6), 
           period_start = make_date(year, if_else(half==1, 1, 7), 1), 
           period_end = make_date(year, if_else(half==1, 6, 12), if_else(half==1, 30, 31))) |> 
    filter(!is.na(`Hours Viewed`)) |> 
    mutate(live_event = !is.na(Runtime) & str_detect(Runtime, "\\d+:\\d+\\*"), 
           clean_time = str_remove(Runtime, fixed("*")),
           Runtime = 60 * hour(hm(clean_time)) + minute(hm(clean_time))) |>
    select(-clean_time) |>
    mutate(Runtime = coalesce(Runtime, mean(Runtime, na.rm=TRUE)), 
           .by=Title, 
           Title = stringi::stri_trans_general(Title, "Latin-ASCII"),
           Title = str_remove(Title, " // .*"), 
           Title = str_remove(Title, "[^[:ascii:]].*"), 
           Title = str_trim(Title)) |>
    filter_out(Title == "") |>
    select(year, 
           period, 
           period_start, 
           period_end, 
           Title, 
           -half, 
           Runtime, 
           Views, 
           `Hours Viewed`, 
           `Release Date`,
           `Available Globally?`, 
           live_event)
}

NETFLIX_DATA <- load_netflix_data()

Observations

This data goes from 1Q’23 through 2Q’26. So, the data is very relevant, and I expect to see some shows I’ve recently watched.

There are 24,427 distinct titles which is a lot but Netflix licenses a lot of shows and movies especially foreign, so I would love to know the distribution of Netflix Originals vs Everything Else.

For runtime the data is skewed, which makes sense because there are some shows that have hundreds of episodes like some soap dramas. I am noticing a lot of null values off the bat and in previous classess I often decide to not drop them.

The views column also includes NA I doubt that means that no one watched the title although it could be the case for some.

Hours viewed is very interesting and I would like to see this column across titles because I had read somewhere that Netflix prioritizes shows that keep customers subscribed which must be the ones that force the users to spend the most time on the platform.

Available globally is interesting because there are some shows Netflix doesn’t have the rights for abroad.

Live event makes sense since Netflix is just recently getting into live sports and live events so the number is significantly lower.

top_titles_by_period <- NETFLIX_DATA |>
  group_by(period) |>
  mutate(
    period_total = sum(hours_viewed, na.rm = TRUE)
  ) |>
  filter(!title %in% c("Other Shows", "Other Movies")) |>
  slice_max(
    order_by = hours_viewed,
    n = 1,
    with_ties = FALSE
  ) |>
  mutate(
    viewing_share = hours_viewed / period_total
  ) |>
  ungroup() |>
  select(period, title, hours_viewed, viewing_share) |>

gini_coef <- function(x) {
  x <- sort(x[!is.na(x) & is.finite(x) & x >= 0])
  n <- length(x)

  if (n == 0 || sum(x) == 0) {
    return(NA_real_)
  }

  (2 * sum(seq_len(n) * x) / (n * sum(x))) -
    (n + 1) / n
}

Strategic Memo

After our evaluation of Netflix’s viewing data from January 2023 through June 2026, we have identified three areas of opportunity for its content strategy, which encompasses live entertainment, original series investment, and licensing of international programming.

As someone working in sports digital advertising at Paramount, I see live events as a promising area of growth. While Netflix has already established a dominant TV and movie portfolio, there was a 33% increase in live events between the beginning of 2025H1 and 2026H1. The first half of 2026 was the best performing period in total viewing hours with 343.2M hours which is roughly 53% higher than the previous 2025H2 half year. What’s even more promising is that the growth in viewing hours is not solely explained by the increase in the number of live events which was roughly 15% more. We will need to do additional analysis on the return on investment of the events taking into consideration how much they cost, how they affect subscriptions, and additional sources of revenue like in-stream ads. However, I recommend that the WWE, which represents about 90% of the live entries and has an average of 2.8M hours per entry, remains the flagship live-programming property. Furthermore, there should be additional massive celebrity-fueled events scattered throughout the year like the Jake Paul vs. Mike Tyson fight as there is tremendous interest this one event holding 21% of all the live viewing hours across 2023H1 through 2026H1.

I recommend that Netflix takes a strategic approach in budget allocation when it comes to series and franchise renewals. This is because total viewing hours concentration as denoted by the Gini Coefficient has increased from 0.738 (2023H2) to 0.752 (2026H1). The Gini Coefficient is a number between 0 and 1 with 0 being an equal distribution, in this case an equal distribution in total viewing hours between titles, and a value closer to 1 being more concentration of viewing hours in fewer titles. However, when adjusting for runtime the number remained much more stable from 0.700 (2023H2) to 0.708 (2026H1). To summarize, the Gini is high, denoting viewing interest is heavily concentrated in a few titles, but this has remained relatively stable. This isn’t surprising when you consider that the top ten most-watched shows represented 6.10% of all the hours in 2026H1, which is an impressive number considering the 8,162 number of reported titles. My strategic advice is to take risks and release multiple S1 shows and see what sticks to the wall or in this case the audience, as a means to find the next Stranger Things or Bridgerton. However, if the show fails to capture excitement then the show should be cancelled. Of course, financial considerations should be taken and being prudent with the budgets would allow for multiple S1 shows. If the show is a hit, then the budget can increase for future seasons.

Netflix should continue serving as the bridge to bring foreign entertainment markets to a global audience. New East Asian shows like Squid Game 840.3M hours (2025H1), King the Land 630.2M hours (2023H2), Pursuit of Jade 356.7M hours (2026H1) have shown the importance of investing in new material. However, what’s even more intriguing is acquiring the rights to properties that were huge for their time in their place of origin, and introducing these to both nostalgic and new users. For example, the 2001 telenovela Pedro El Escamoso had a total of 161.2M viewing hours. It generated 15.3M hours in 2026H1 outperforming the dataset average of 9.1M for the same period.

I suggest that Netflix cultivates this already established loyal audience by continually expanding their licensing of telenovela hits across LATAM.

To summarize, live entertainment is still an area of untapped growth potential and we should continue investing in the WWE franchise whilst scattering around major live events akin to the Jake Paul vs Mike Tyson fight. When it comes to budget allocation, Netflix should work around its highly concentrated viewing consumer behaviors and surgically try to find the next big franchise. Finally, Netflix should take advantage of already established international audiences by continuing to expand its licensing portfolio of international telenovelas.
